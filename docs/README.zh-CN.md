# MinimalGPT

> [!WARNING]
> **项目已停止维护——需要更新。** 据作者反馈，0.0.3 版过去曾正常工作，但后来再次尝试时已无法正常使用。0.0.4 版仅为降低界面误操作风险而进行的归档安全修订，**并非经过验证的兼容性更新**。与当前 ChatGPT 界面的兼容性**尚未验证**。本仓库仅提供参考源代码，不代表扩展程序已可正常使用或仍受到维护。

MinimalGPT 是一款基于 Chromium Manifest V3 的实验性扩展程序，旨在减少 ChatGPT 界面的视觉干扰，并不替代 ChatGPT 本身。设计用途为**每个浏览器标签页显示一个对话**。

## 项目状态

**已停止维护。** 据作者反馈，最后一次确认曾正常工作的版本为早期使用的 0.0.3 版；此后故障的原因和影响范围尚不明确。作者后来还反馈，0.0.4 版未能隐藏大部分预期的聊天控件。ChatGPT 界面会独立于本扩展发生变化，因此 CSS 选择器可能不再匹配页面元素。0.0.4 版是**采用更谨慎规则的归档安全修订**，而不是已经验证兼容性的版本：它尽量降低误隐藏其他控件的风险，并在全新安装时默认关闭。项目不保证更新、兼容性或技术支持，也不声称与 OpenAI 或 ChatGPT 存在官方关联。

如果页面控件消失或界面出现异常，请按 `Alt+M` 关闭 MinimalGPT，然后重新加载 ChatGPT 标签页。如果快捷键无效，请在 `chrome://extensions/` 中禁用或移除扩展程序，再重新加载页面。请勿依赖本项目完成关键工作。

## 预期行为

手动开启后，主要依靠 CSS 的极简模式尝试隐藏能够识别的侧边栏、顶部栏、分享按钮、部分语音及听写控件，以及部分回复操作按钮；输入框、附件、发送和复制功能应予以保留。在能够识别相关元素时，它还会减弱输入区域的装饰性阴影，并调整阅读区域宽度。实际效果取决于 ChatGPT 当前的 DOM 结构和界面语言。当元素标识发生变化时，部分控件可能继续显示；这比误隐藏无关功能更可取。

MinimalGPT 不拦截网络请求、不读取账户凭据、不加载远程代码，也不安装 DOM 观察器。它仅申请 Chromium 的 `storage` 权限，只在 `https://chatgpt.com/*` 上运行，并在本地保存一项开启／关闭偏好。安装不再维护的扩展程序前，请先检查其源代码。

## 文件

- `manifest.json`：扩展程序配置、默认语言和权限。
- `_locales/en/messages.json`：英语名称、说明和状态消息。
- `_locales/pt_BR/messages.json`：巴西葡萄牙语消息。
- `_locales/es/messages.json`：西班牙语消息。
- `_locales/ru/messages.json`：俄语消息。
- `_locales/zh_CN/messages.json`：简体中文消息。
- `docs/README.pt-BR.md`、`docs/README.es.md`、`docs/README.ru.md`、`docs/README.zh-CN.md`：对应语言的完整文档。
- `minimal.css`：可选的视觉样式规则；翻译工作未修改此文件。
- `content.js`：本地偏好、`Alt+M` 开关和本地化状态提示。
- `tests/`：无需额外依赖的静态及模拟测试；不验证真实浏览器中的兼容性。
- `.github/workflows/smoke.yml`：在代码变更和拉取请求时自动运行基本测试。

## 语言

英语（`en`）为默认语言；另提供巴西葡萄牙语（`pt_BR`）、西班牙语（`es`）、俄语（`ru`）和简体中文（`zh_CN`）。Chromium 根据浏览器语言选择可用的翻译；没有匹配的译文时使用英语。**本次计划中的五种语言均已包含，但不包括繁体中文。**

**浏览器语言可能与 ChatGPT 网站的界面语言不同。** 翻译 MinimalGPT 的消息不会修改识别网站控件所用的 CSS 选择器，也不会修复此前报告的兼容性问题。本次翻译不改变扩展程序的功能。

## 本地安装与检查（风险自负）

1. 下载或克隆本仓库，并检查其中的文件。
2. 在 Chromium 中打开 `chrome://extensions/`，启用**开发者模式**，然后选择**加载已解压的扩展程序**（具体名称因浏览器而异）。
3. 选择包含 `manifest.json` 的文件夹。
4. 重新加载 `https://chatgpt.com/`。为降低风险，全新安装默认**关闭**；按 `Alt+M` 可手动开启。
5. 更新源代码后，先在 `chrome://extensions/` 中重新加载扩展程序，再重新加载 ChatGPT 标签页。

本地偏好会在重新加载后保留。如果已有安装曾保存开启状态，则会一直保持开启，直到明确关闭。浏览器或网站的快捷键可能与 `Alt+M` 冲突；如果无法使用该快捷键，请在 Chromium 扩展程序页面禁用本扩展。

## 测试与局限

使用 Node.js 22 运行 `node --test tests/*.test.cjs`。这些测试检查清单文件、翻译键、CSS 中的静态安全约束，以及模拟的快捷键和存储行为。**测试不能验证 ChatGPT 当前界面、无障碍可访问性或端到端运行情况。** 在声称某个版本兼容之前，必须在真实浏览器中手动测试。

已知局限：扩展程序依赖 ChatGPT 私有且未公开文档的 DOM 属性；功能、语言和布局可能有所不同；没有自动检测兼容性问题或自行修复的机制。请勿添加过于宽泛的规则，例如隐藏所有 `header` 元素、隐藏除“复制”以外的所有按钮，或仅因元素标识中包含 `audio` 就将其隐藏。

## 版本历史

- **0.0.4（2026-09-22）：**归档安全修订：增加停止维护警告、全新安装默认关闭、采用更谨慎的 CSS 选择器并增加基本测试。**与当前 ChatGPT 的兼容性尚未验证。** 作者随后反馈，大部分预期界面调整没有生效。未经请求的 0.0.5 版选择器修改已经撤销；国际化以 0.0.4 的源代码为基准。
- **0.0.3（2026-08-27）：**更新语音、听写及回复操作的选择器；作者称该版本曾正常工作，但后来报告了故障。
- **0.0.2：**提供每标签页一个对话的低视觉干扰模式，并减少动画。
- **0.0.1：**初始 Manifest V3 扩展程序，提供 `Alt+M` 开关和本地偏好持久化。
